Twenty shares NestJS/PostgreSQL/Redis concepts with SAAS but uses a much larger metadata-driven TypeORM/GraphQL platform. Frappe CRM uses Python/Frappe + Vue with DocType metadata and framework-provided lifecycle/permissions. EspoCRM uses PHP/ORM + metadata-driven browser views and explicit ACL/job interfaces. Adopting any complete platform would add a migration and operational burden without validating the target manager workflow. Keep the existing modular monolith.
